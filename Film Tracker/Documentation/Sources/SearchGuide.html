Chapter 1

The basics

There are two kinds of search: plain text, and tokens. Plain text is the quick way to find a title. Tokens are how you ask precise questions about any other part of a film.

Opening the search field

The search field is in the window’s toolbar and always searches the entire film library, regardless of which sidebar item you were looking at. Press ⌘F (View > Search Film Library) to jump straight into it from anywhere. When you clear the search, you return to the view you started from.

The search results have their own sort, filters, and grid or list style, which start fresh with every search. They stay in effect for as long as the search field holds anything, including a pill with no text beside it. To start over completely, empty the field, pills included.

Plain-text search

Type any text; results update as you type. Plain text matches against a film’s title and its alternate titles. Matching is not case-sensitive, and the text can appear anywhere inside the title, not only at the start. Accents and punctuation are ignored, and every kind of dash counts as the same character, so you can type titles the way your keyboard writes them.

You typeFinds
matrixThe Matrix, The Matrix Reloaded, and any film with “matrix” in an alternate title

THE GODFATHERSame as lowercase; capitalization never matters
mission impossible falloutMission: Impossible – Fallout; the colon and the dash are ignored
amelieAmélie; accents never matter
spidermanSpider-Man; punctuation inside a word is ignored, so “spider-man” finds it too

Suggestions and recent searches

As you type, a menu below the field suggests values from your library: titles for plain text, and, once you type the space after a field name, that field’s values (people for #cast, tags for #tag, list names for #list, and so on). Picking a suggestion adds it exactly as shown. The closest matches to what you type always come first. Among similar matches, suggestions rise when you search for them often, when they relate to the pills already in the field or to your recent searches (after #director nolan, #cast lists his regular cast first), and when they belong to films you rate highly, watch often, watched or added recently, have queued or ranked in the Hall of Fame, or have a release coming soon. Values you have searched for before are suggested even when they are not library text, such as a year range. You can also type initials (tdk for The Dark Knight) or words in any order (hanks tom). Clicking the empty field lists your ten most recent searches from this session; pick one to run it again. The menu shows at most 30 rows.

Both are on by default and can be turned off in Settings > General. Recent searches are kept only until you quit Film Tracker. What the suggestions have learned is kept on this Mac, and it fades over time when you stop using it.

Tokens: asking about something other than the title

A token pairs a field (such as Director or Rating) with a value (such as “kubrick” or “8+”). Tokens appear in the search field as small rounded pills, like the ones on the cover.

Creating a token

  1. Type #. The search field switches into token entry and a list of every field appears below it. While you are entering a token, the results hold still; they update once the token is confirmed.
  2. Type the field name, or pick it from the list. You can type any name or shortcut from Chapter 3 (#director, #dir, #rating, #lastwatched) or the full display name with spaces (#last watched, #executive producer). The list narrows as you type.
  3. Press Space, then type the value. Everything after the field name, spaces included, is the value: #cast tom hanks searches for “tom hanks”.
  4. Press Return. The token becomes a pill and the results update. Nothing happens if there is no value yet, so a bare #director followed by Return does not create a token.
⚲ #director kubrick  ← type this, then press Return
⚲ Dir: kubrick  ← the confirmed token
TipYou can keep typing plain text after a token is made, and you can add as many tokens as you like. Typed text always narrows by title, on top of whatever the tokens do.

Shortcuts into search from the sidebar

In a film’s Details tab, the Studio, Cast, Director, Producer, Executive Producer, Screenwriter, and Composer sections each show a small magnifying-glass button beside every name. Clicking one performs that search immediately, creating the token for you.

Removing a token

Delete the pill the same way you would delete any token in a macOS search field: select it and press Delete, or place the cursor after it and press Delete once. The results update immediately.

What the pill shows

How matching works

Unless a chapter says otherwise, a text value matches when it appears anywhere inside the stored text, ignoring capitalization, accents, and punctuation. Runs of spaces count as one space. #director nolan finds “Christopher Nolan”; #genre sci finds “Sci-Fi”. You never need wildcards, and you never need quotation marks around multi-word values.

One character to avoid

Do not use # inside a value (for example in a note you are looking for). The last # in the field always starts a new token.

Chapter 2

Combining tokens

Every token can be given one of three behaviors by a prefix typed straight after the #: the default AND, an OR with /, or a NOT with !.

You typePillMeaning
#director kubrickDir: kubrickAND. The film must match this token. With several AND tokens, a film must match all of them.
#/director kubrick/Dir: kubrickOR. Films matching this token are added to the results, whether or not they match the other tokens.
#!genre horror!Genre: horrorNOT. Films matching this token are removed from the results.
#/!genre horror/!Genre: horrorOR and NOT together. The slash comes first. This behaves exactly like NOT: it removes matches.

Typing the prefix is the only difference. After # you can type /, !, or /!, and the field list shows a green “Or” or a red “Not” beside each field to confirm the mode.

AND: narrowing down

Each additional AND token trims the results further. This is the most common way to search.

⚲Dir: spielbergYear: 1990-1999Rating: 7+

Result: Spielberg films released in the 1990s and rated 7 or higher.

Two tokens of the same field are also ANDed. #cast tom hanks plus #cast meg ryan returns only films listing both actors.

OR: widening

An OR token contributes its own matches to the results. To find films by either of two directors, make both tokens OR:

⚲/Dir: kubrick/Dir: scorsese

Result: every Kubrick film plus every Scorsese film.

OR is not parenthesized

OR tokens are checked against the whole library, not against what the AND tokens have already narrowed to. The results are: (all AND tokens together) plus (anything matching any OR token). So Rating: 8+ with /Dir: kubrick returns every film rated 8+ and every Kubrick film, rated or not. It does not mean “Kubrick films rated 8+” (use two plain AND tokens for that).

It follows that you cannot express “(A or B) and C” in one search. When you need that, run the OR search first and sort or scan the result, or find a field that covers both A and B (the Crew token, for example, covers every credited person at once).

NOT: excluding

A NOT token removes its matches from everything that survives the positive tokens. Because it is applied last among the tokens, it also removes films that an OR token brought in.

⚲Studio: a24!Genre: horror

Result: A24 films that are not horror.

A NOT token on its own is also fine: #!genre documentary returns every film that is not a documentary.

The order of operations

  1. All AND tokens narrow the library to the films matching every one of them.
  2. All OR tokens are matched against the whole library and their matches are added in.
  3. If there are only OR tokens, the OR matches are the whole result; if there are only AND tokens, the AND matches are.
  4. All NOT tokens remove their matches.
  5. Any plain text you typed narrows what is left by title.
Reading a NOT as “the opposite”

A NOT token returns every film the plain token would not have returned. That makes it exact for questions of the form “everything except”, and it also means that a value the app cannot interpret (a misspelled keyword, say) turns into every film when negated, because the plain version matched nothing. See Chapter 10.

Two-word field names: a trap

The app reads the field name left to right and stops at the first word that is a field name by itself. That is harmless for most names (#last watched 2023, #executive producer spielberg, and #user rating 8+ all work), but two fields contain a word that is a complete field name of its own:

  • #date added 2024 is read as Year (date) with the value “added 2024”.
  • #rotation threshold 24 is read as Rotation Threshold with the value “threshold 24”, which matches nothing.

Type these as one word (#dateadded, #rotationthreshold), use a shortcut (#added, #rotation), or pick the field from the suggestion list, which always inserts the correct form.

Easy to mix up

#date means the film’s release year, not the date you added or watched a film, and not the date of one of its disc releases (that is #release 2027; Chapter 7). For those use #added and #watched. Likewise #studio is the studio credited on the film itself, while the studio or distributor of an individual disc is searched through #release (Chapter 7).

Chapter 4

Text tokens

These tokens match words. The value may be any part of the text you are looking for, in any capitalization, and may contain spaces.

Title

#title behaves exactly like plain text typed in the field: it checks the title and any alternate titles. Its use is for combining with NOT or OR, for example #!title star to hide every film with “star” in its title.

People

#crewAll six of the above at once: a film matches if the name appears in any of them
QueryFinds
#director nolanFilms with a director whose name contains “nolan”

#!director sofiaCoppola films, minus the ones whose director list also matches “sofia”
Tip

Searching a surname alone is the safest way to find someone, since spelling of first names and middle initials varies. Use the full name when a surname is common, because the match is on the letters, not on whole words.

Genre, Studio, Tags

  • #genre matches the film’s genre text. #genre sci finds Sci-Fi; #genre drama finds Drama and Crime Drama.
  • #studio matches the studio or studios credited on the film itself.
  • #tags matches any of the film’s tags. A film matches if any one of its tags contains the text.

Notes

#notes searches both of the free-text areas a film carries: your own notes and the film’s description notes. A match in either one counts. It does not look at the film’s plot summary; that is what #synopsis is for.

Synopsis

#synopsis (also #plot and #description) searches the film’s plot summary. It behaves differently from the other text tokens: it looks for every word you type, in any order, rather than for the exact text you typed.

QueryFinds
#synopsis detective sins millsSeven (1995): its summary mentions a detective, Mills, and the seven deadly sins, though not in that order
#plot heist vaultAny film whose summary contains both “heist” and “vault”
#description vampireA single word works too
#!synopsis alienEvery film whose summary does not mention “alien”
  • Every word must be present. Adding a word only ever narrows the results, so if a search finds nothing, drop the least certain word.
  • Words, not phrases. #synopsis serial killer finds summaries containing “serial” and “killer” anywhere, not necessarily next to each other.
  • Each word matches inside longer words, like every text token: murder finds “murders” and “murderer”, but murders does not find “murder”. Type the shortest stem that is still distinctive.
  • Leave punctuation out. Type detective, not detective,; a comma becomes part of the word being looked for.

List

#list finds films that belong to the list you name. Once you type the space after #list, the suggestion list shows every list you can search, narrowing as you type; pick one to add it as a pill. It searches your own lists, the built-in smart lists (as long as smart lists are enabled in Settings), and the two ranked lists in Reports: Hall of Fame and Release Wishlist (a film is on the wishlist when at least one of its releases is wishlisted), and the five Recents tabs. The internal Film Queue lists are not searchable this way.

A Recents tab matches exactly the films that tab shows, up to its 200 most recent. In suggestions these are marked “Recents:”.

Chapter 5

Number tokens

Year, Duration, and Rating understand comparisons and ranges. Type the number on its own for an exact (or at-least) match, put a symbol with it, or give a range with a hyphen between two numbers.

Year

The film’s release year. Years are plain four-digit numbers.

QueryFinds
#year 1999Films released in exactly 1999
#year 1990-19991990 through 1999, both ends included
#year >2010Released after 2010 (2011 and later)
#year <1960Released before 1960 (1959 and earlier)
#!year 1990-1999Everything except the 1990s, including films with no year recorded

Films with no release year recorded are left out of every range, greater-than, and less-than search.

Duration

Runtime in whole minutes. Do not type hours or units; #duration 2h means nothing to the search. For a film marked as edited that has an edited runtime, the search uses that edited runtime; every other film uses its regular runtime.

QueryFinds
#duration 120120 minutes or longer (a bare number means “at least”, not “exactly”)
#duration >150Strictly longer than 150 minutes
#duration <90Strictly shorter than 90 minutes
#duration 90-120A range: 90 to 120 minutes, both ends included

Films with no duration recorded are skipped by ranges and by “shorter than” searches.

Rating

Your own rating, from 0 to 10. A rating of 0 means Not Rated, so the searches below that say “at most” or “less than” never include unrated films by accident.

QueryFinds
#rating 8Rated exactly 8
#rating 8+Rated 8 or higher (at least 8)
#rating 8-Rated 8 or lower, but rated (unrated films are excluded)
#rating >7Rated above 7 (8, 9, 10)
#rating <5Rated below 5 and rated (1 to 4)
#rating 0Films you have not rated
#rating 7-9A range: rated 7, 8, or 9, both ends included
Ranges and the hyphen

A range needs a whole number on both sides of the hyphen: 7-9. A hyphen with nothing after it keeps its older meaning for ratings (8- is “8 or lower”). Ranges are read literally, so #rating 0-3 includes unrated films, which the “or lower” and “less than” forms deliberately leave out. A range written backwards, such as 9-7, matches nothing.

Tip

A number that is not a number (#rating good) returns no films, so if a numeric search comes back empty, check the value for stray letters.

Chapter 6

Date tokens

Last Watched is the date you most recently watched a film. Date Added is the date it entered the library. Both accept exactly the same forms.

Relative dates

The words today, week, month, and year, on their own or after last, past, previous, or this, are rolling windows, so “past week”, “this week”, and “last week” all mean the same thing. Give a number to widen the window: last 3 months, past 10 days, or just 6 weeks.

QueryFinds
#watched todayWatched since the start of today
#watched weekWatched in the past seven days
#watched past monthWatched in the past month
#added yearAdded within the past twelve months

The windows are rolling: “week” is the last seven days counting back from this moment, not the calendar week.

Decades

2010s is 2010 through 2019. Two digits work too, with or without an apostrophe: 90s and ’90s are the 1990s, 10s the 2010s. Add early, mid, or late: early 2000s.

Writing a phrase

Capitals, apostrophes, and commas never matter (New Year’s Eve is new years eve). Filler words are ignored wherever they appear: about, around, roughly, approximately, circa, the, on, in, of, during, and sometime. So #watched sometime around 2 months ago and #watched in the last 3 months both work.

Before and after

Put > (after) or < (before) in front of a year or a full date. Both are exclusive: the date you name is not itself included.

QueryFinds
#watched >2022Watched in 2023 or later (after the end of 2022)
#watched <2020Watched in 2019 or earlier (before the start of 2020)
#added >2024.06.30Added after June 30, 2024
#added <2021-01-01Added before January 1, 2021

A year-range for a date field is built from two tokens: #watched >2018 with #watched <2021 finds films watched in 2019 or 2020.

A particular year, month, or day

QueryFinds
#watched 2025Watched at any time in calendar year 2025, from January 1 through December 31
#watched december 2020Watched at any time in December 2020
#watched dec 2020The same, with the abbreviated month
#watched dec, 2020The same; a comma after the month is accepted

No date at all

The keyword none (or never) finds films with no date recorded for the field. For Last Watched that means no viewing date.

QueryFinds
#watched noneFilms with no viewing date recorded
#!watched noneFilms with a viewing date
A date is not the same as “watched”

Last Watched searches the viewing date. A film you marked as watched without a date (common for viewings that predate the dates you started recording) is found by #watched none, because it has no date. The watched flag itself has no search token yet; the Filter menu offers it.

When a date is not understood

A value that is not in any of the forms above, or that names a date that does not exist (#watched >2020.13.45, #watched soonish), finds nothing, exactly as a misspelled title does. Negated, it finds every film (#!watched soonish), because a NOT returns whatever the plain search did not.

Chapter 7

The Release token

A film can have several releases (a 4K disc, a Blu-ray, a DVD, a wishlist entry). #release asks whether a film has at least one release with a given property. The value is a keyword from the list below; capitalization does not matter.

How to read the results

A film matches if any of its releases has the property. Two Release tokens are checked independently, so #release 4k with #release purchased finds films that have a 4K release and have a purchased release, which may be two different discs. For “a purchased 4K disc” use the smart list instead: #list purchased 4k.

Ownership

Type any ofMatches films with…
purchased   owneda release you have purchased
unpurchased   wishlist   wanteda release you have not purchased (a wishlist release)

Release date

A release’s own date, which can be up to a year ahead. These forms are read as dates only when the whole value is one of them, so a distributor’s name is never mistaken for a date.

TypeMatches films with…
upcoming   unreleased   preorder   pre-ordera release whose date is still ahead, purchased or not (the same films as the Upcoming Releases smart list)
2027a release dated in that year
2020-2027a release dated in that span of years, both ends included
>2026   <2020a release dated after or before that year
>2026.10.01   <2020-06-15a release dated after or before that day (the day itself excluded)
March 2027   Mar 2027a release dated in that month
2027.03.14a release dated that day

A release recorded with only its year matches the year forms, and a day form only when the whole year lies on one side of the day: a release known only as “2026” is neither before nor after 2026.06.01. The relative and natural phrases of the date tokens (past week, last summer) are not accepted here; they look back from today, and a release date can lie ahead.

Write bluray or blu-ray as one word; blu ray with a space is not recognized.

Anything else: distributor or studio

If the value is none of the keywords above, it is matched against the studio or distributor of each release, as text. #release criterion finds films with a Criterion release; #release shout finds Shout! Factory releases. This is the disc’s own studio, which is separate from the film’s studio searched by #studio.

Keywords win over studios

Because keywords and dates are checked first, a distributor whose name is also a keyword (or contains one, such as one containing “4k”) will be read as the keyword. Include more of the name to steer around that.

Chapter 8

The Rotation Threshold token

The rotation threshold is how long a film rests before it comes up for rotation again. Each film either follows the global default (set in Settings > General) or carries its own override. The token can search by the threshold value or by whether an override exists.

Searching by value

Available thresholds are 12, 18, 24, 36, 48, and 60 months (1, 1½, 2, 3, 4, and 5 years). Write the value as months or years, with or without a unit.

QueryReads as
#rotation 2424 months. A bare number is tried as months first.
#rotation 2Not a valid month count, so read as 2 years = 24 months
#rotation 2 years24 months. Also accepted: 2 year, 2 yr, 2 yr.
#rotation 24 months24 months. Also accepted: 24 month, 24 mo, 24 mo.
#rotation 1.51½ years = 18 months

A value search matches a film’s effective threshold. That is the film’s override if it has one, otherwise the current global default. So if the default is 2 years, #rotation 2 years finds both films explicitly set to 2 years and films that simply follow the default.

Values the app cannot map to a real threshold return no films: 6 months, 7, 36 years, and 2 dingus all return nothing. A unit must be a real one, and a month value must be an exact whole number.

Searching by override

Three keywords test whether a film has its own threshold set, regardless of what number it is.

QueryFinds
#rotation defaultFilms set to Default, with no override of their own
#rotation overrideFilms with an override of any value
#rotation customThe same as override
#!rotation defaultThe same as override: everything not following the default
Default means “set to Default”

With a 2-year default, a film whose threshold has been explicitly changed to 2 years has an override (it just happens to match the default today). It does not appear under #rotation default, and it does appear under #rotation override, #rotation custom, and #rotation 2 years. If you later change the global default, that film keeps its 2 years, while films set to Default follow the new value.

Putting them together

QueryFinds
#rotation override
#!rotation 5 yearsFilms with an override that is not 5 years
#rotation override
#rotation 12Films explicitly set to 12 months
#rotation default
#list up for rotationFilms currently up for rotation that follow the default

Chapter 10

Troubleshooting

Almost every surprising result comes from one of the situations below.

What you seeWhat is going on
Results do not change after I type #director kubrickPress Return. Until you do, the search is paused and the results show what the previous tokens found. The token also needs a value after the field name and a space.
The “Enter Search Token” message appearsYou started a token (typed #) but have not confirmed one yet. Finish it with a value and Return, or delete the # text.
I pressed Return and nothing happenedThe text after # is not a field name. Check the spelling against Chapter 3 or choose from the suggestion list.
A number search returns nothingNumber tokens take digits and the symbols > < + - only. Letters, units, and words make the search match nothing.
A date search returns nothingThe date was not understood (a misspelled word, a day or month that does not exist, a symbol in the wrong place). Chapter 6 lists every form that is.
A NOT search returns the whole libraryThe value was not understood, so the matching version found nothing, and the opposite of nothing is everything. Check the value.
Rating “8-” or “<5” does not show unrated filmsBy design: 0 means Not Rated, and “at most” or “less than” searches leave those out. Use #rating 0 to find them.
#list purchased also shows unpurchased films“Unpurchased” contains the word “purchased”. Add #!list unpurchased.
My OR token brought in films I did not expectOR tokens are not limited by AND tokens. See the warning in Chapter 2.
#release value finds nothingIt may match no keyword and fall through to a distributor name. Check Chapter 7 for the exact spelling, including bluray without a space.
A smart list name finds nothingSmart lists must be enabled in Settings for #list to see them. Film Queue lists are never searchable.
A rotation value finds nothingOnly 12, 18, 24, 36, 48, and 60 months (1, 1.5, 2, 3, 4, 5 years) exist. Anything else, including a number with an unknown unit, matches nothing.
A film appears that does not seem to matchMatching is by letters, anywhere in the text, so a short value matches inside longer words. Lengthen the value.
